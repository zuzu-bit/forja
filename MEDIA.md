# Media licențiată — scoaterea watermark-ului, LEGAL și GRATUIT

Toate pozele și clipurile din FORJA sunt preview-uri din **colecția FREE Adobe Stock**
(de aceea au watermark). Ele se licențiază **gratuit** cu un cont Adobe gratuit —
primești originalele fără watermark, cu licență valabilă comercial.

## Pașii (o singură dată, ~30–45 min)

1. Fă-ți cont gratuit pe [stock.adobe.com](https://stock.adobe.com) (Sign in → Create account).
2. Pentru fiecare rând din tabel: deschide linkul → apasă **„Descarcă gratuit” / „Free download”**
   (asset-urile sunt din colecția Free — nu cer card).
3. Redenumește fișierul descărcat EXACT ca în coloana „Nume fișier”.
4. Deschide [dash.cloudflare.com](https://dash.cloudflare.com) → **R2 Object Storage** →
   bucket-ul **forja-media** → **Upload** → trage toate fișierele.
5. Gata. La următoarea pornire, aplicația folosește automat originalele (fără build nou).
